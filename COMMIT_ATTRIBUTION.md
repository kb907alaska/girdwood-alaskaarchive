# FMG commit attribution standard

Commit subject: `ORG-ACTOR - Description`. FMG assistant: `FMG-GPT - Description`. Martin Media: `MARTINMEDIA-HUMAN - Description` (or verified actor code). Client: `CLIENT-HUMAN - Description` (prefer an agreed client code). The prefix names the organization **actually responsible for the change**, not the repository owner.

For multiline commit messages include verified trailers: `Change-Org: FMG`, `Change-Actor: GPT`, `Change-Project: <repository>`, `Change-Source: AI-assisted`. Replace values with actual contributor data. This is metadata, not a cryptographic signature. Preserve Git author/committer records and don't rewrite published history for cosmetic attribution.
